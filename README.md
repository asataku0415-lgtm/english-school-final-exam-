# english-school
英会話スクールサイト（スクール最終課題）

## サイト概要
オンラインスクールの最終課題として制作した、英会話スクールのランディングページです。
ヘッダーからフッターまで、キャンペーン、コース案内（タブ切り替え）、３つの特色、講師紹介、料金プラン、FAQなどを１ページにまとめ、
HTML/CSSとjQueryプラグイン（スライダー/タブ/アコーディオンメニュー）を使ってコーディングしました

スマートフォンではハンバーガーメニュー、PCでは横並びナビに切り替わるレスポンシブヘッダーや、
スクロール時のフェードイン演出、タブ/アコーディオンUIなど、動きのあるページ構成を実装しています。

## アピールポイント
- SP：ハンバーガー/PC：横並びの固定ヘッダー実装（レスポンシブ対応）
- メインビジュアルとキャンペーンエリアの装飾（角丸画像＋カラーバリエーションのテキスト）
- コース案内のタブ切り替えレイアウトと、カード風のコース紹介ボックス
- ３つの特色セクションでの左右交互レイアウト＋スクロール時のフェードインアニメーション
- 料金表（テーブル）のスタイリングと、FAQのアコーディオンUIで、情報量の多いセクションを整理
